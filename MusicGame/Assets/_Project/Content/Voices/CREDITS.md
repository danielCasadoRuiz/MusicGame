# Character voices — origin and licence

All the clips under this folder are **generated by us** during production with Qwen3-TTS (Apache-2.0, run locally, see `Tools/VoiceGen/LICENSES/THIRD_PARTY.md`). The generated audio is our own work and carries no third-party restriction.

- Each voice is a **fictional persona**, designed from a text description in `Assets/_Project/Audio/Voices/Definitions`. It is not an imitation, a clone or a recording of any real person.
- The same identity (one reference per voice) is used for all lines and languages.
- The texts come from the game's own dialogue tables (`Localization/ComposerDialogues`).
- Production masters (24-bit) and the generation manifest live outside the project, in `AssetsMaterial/VoiceMasters/`.
- **Do not edit these clips by hand.** Regenerate them with **Tools > MusicGame > Audio > Voice Production**.
