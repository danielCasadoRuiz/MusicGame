# Jukebox owner / accepted B–D direction

Implemented in the real Jukebox prefab. The owner is selected from AppConfig's opponent roster each time JukeboxController.Open succeeds, avoiding the previous owner when alternatives exist. It remains stable throughout that visit. This does not change progress, unlocked music or store entitlements.

The name is independent TextMesh Pro text, using the existing Libre Baskerville display font and a shared engraving material. The plate's centre is extendable; the two ends retain a 48.60-unit width at a 40-unit plate height, including their decorative shoulders and rivets. Width is bounded to 260–470 units and long labels can reduce text size. No image is generated per name.

Four circular masks follow the four authored medallion frame centres; cover images retain their own aspect ratio and fill those masks. The block and circles are placed further right, above the existing UI instead of taking space from the song panel. The stand and four empty brass frames are now painted directly into CabinetOwnerIntegrated.png, matching the cabinet wood and lighting. No separate stand or cleared-top patch is rendered. The plaque, masked cover images and foreground papers remain independent. The approved overlapping paper-bank proposal is integrated as three tightly registered texture regions to avoid a full-screen transparent draw.

## Assets

- `MusicGame/Assets/_Project/Art/UI/Jukebox/OwnerPlaqueBlank.png`: blank brass plate, no baked name.
- `MusicGame/Assets/_Project/Art/UI/Jukebox/OwnerMedallionStand.png`: mahogany block and four empty brass frames.
- `MusicGame/Assets/_Project/Art/UI/Jukebox/CabinetClearedTop.png`: cleared cabinet reference, used only for the upper-right patch.
- `MusicGame/Assets/_Project/Art/UI/Jukebox/ScatteredScoresV7.png`: registered transparent paper bank / two airborne pages.

All four assets were produced with the built-in image generation tool from the supplied game artwork / approved reference concepts, with actual alpha transparency. Prompts requested: (1) blank D-style brushed-brass plate with exactly two rivets, shaped fixed ends and an uninterrupted stretchable central field; (2) D-style low mahogany pedestal supporting exactly four empty round gold medallions, no plate or text; (3) foreground-only extraction of the v7 paper bank at the same registered 16:9 positions, everything else transparent; (4) removal of only the old upper-right frames/envelopes from the cabinet, rebuilding the uninterrupted shelf and retaining the curved crest. No generated UI screenshot is used as a game texture.
